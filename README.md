# type-dex

A Pokemon Companion App to help you quickly discover Pokémon type match-ups for your next battle!

- Search for any Pokémon type to instantly see which types it is _strong_ or _weak_ against

## Tech Stack

- Vue
- VueRouter
- Pinia

## Project Setup

Scaffolded with [Vite Configuration](https://vite.dev/config/).

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
